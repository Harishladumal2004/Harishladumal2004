## My Data Analytics Workflow

1. **Understand the Business Problem** — Identify the questions that need answers.
2. **Collect Data** — Work with CSV files, Excel spreadsheets, and SQL databases.
3. **Clean Data** — Handle missing values, duplicates, and inconsistent formats.
4. **Analyze Data** — Use SQL, Python, Excel, and statistics to discover patterns.
5. **Visualize Insights** — Build dashboards and reports using Power BI and Tableau.
6. **Communicate Findings** — Explain trends and recommend data-driven business actions.
